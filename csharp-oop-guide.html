01 — Core OOP Concepts
📦
Encapsulation
Wraps data + methods into one unit; control access via properties.
// Private field, public controlled property private decimal _salary; public decimal Salary { get => _salary; set => _salary = value > 0 ? value : 0; }
🎭
Abstraction
Show only what the caller needs; hide implementation using abstract or interface.
// Caller doesn't know if it's Email or SMS INotification notifier = new EmailNotification(); notifier.Send("Order Confirmed");
🔀
Polymorphism
Same method name, different behavior. Overloading = compile-time. Overriding = runtime.
// Runtime: correct Draw() is called based on actual type Shape s = new Circle(); s.Draw(); // → Circle.Draw()
🧬
Inheritance
Child class automatically gets parent's fields and methods. Promotes reusability.
class Animal { public void Breathe() {} } class Dog : Animal { public void Bark() {} } // Dog inherits Breathe() — no duplication needed
🏛️
Class
Blueprint/logical unit containing fields, properties, methods, and constructors. Reference type; stored on heap.
📍
Object
An instance of a class. var dog = new Dog(); — dog is the object in memory.
02 — C# Data Types
🔢
Value Types
Stored on stack. Copied on assignment. Includes:
int / float / doublechar / boolenumstructint? nullable
🔗
Reference Types
Stored on heap; variable holds a reference.
classinterfacearraydelegate
🔒
Struct
Value type grouping related fields. Best for small, immutable data.
struct Point { public int X, Y; } Point p = new Point { X=10, Y=20 };
📋
Enum
Named constants for a group of integers. Improves readability over magic numbers.
enum OrderStatus { Pending=0, Active=1, Closed=2 } var s = OrderStatus.Active;
🏷️
Record Type
Immutable reference type with built-in value equality. Ideal for DTOs.
record Product(int Id, string Name, decimal Price); // Immutable, equality by value out of the box
🔄
yield Keyword
Returns elements one at a time — lazy evaluation, no full list in memory.
IEnumerable<int> GetEven(int n) { for(int i=2; i<=n; i+=2) yield return i; }
🧩
Partial Class
Split a class across multiple files; compiler merges them. Common in EF migrations and WinForms designer files.
🏷️
Attributes
Metadata decorators inheriting from Attribute. Used for validation, routing, serialization.
[Required] [MaxLength(100)] public string Name { get; set; }
03 — Access Modifiers
public
Accessible from anywhere — any class, any assembly.
private
Only within the same class. Default for class members.
protected
Same class + derived classes.
internal
Within the same assembly (.dll / .exe).
protected
internal

04 — Class Members
🏗️
Constructor
Called on object creation. Initializes state. Can be overloaded.
class Order { public Order(int id) { Id = id; } public int Id { get; } }
📝
Property & Indexer
Property = controlled access to private field. Indexer = array-like access on a class.
public string Name { get; private set; } // Indexer: public T this[int i] { get => _list[i]; }
05 — SOLID Principles
S
Single Responsibility — One class, one reason to change.
InvoiceService handles invoices only — not sending emails.
O
Open / Closed — Open for extension, closed for modification.
Add new discount type via new class — don't edit existing logic.
L
Liskov Substitution — Subclass must work wherever base class is used.
Square shouldn't break code written for Rectangle.
I
Interface Segregation — Don't force clients to implement unused methods.
Split IPrint and IFax instead of one IMultiFunction.
D
Dependency Inversion — Depend on abstractions, not concretions.
Inject IEmailService — not concrete EmailService class.

🔂
Singleton
One instance app-wide with a global access point.
// DI registration — one instance for app lifetime services.AddSingleton<IConfig, AppConfig>();
🏭
Factory
Creates objects without exposing creation logic to the caller.
// Returns Stripe or PayPal based on input IPayment p = PaymentFactory.Create("stripe");
🎀
Decorator
Wraps an object to add behavior at runtime without modifying its class.
IOrderService svc = new LoggingDecorator(new OrderService()); // Logging added without touching OrderService
♟️
Strategy
Swap algorithms at runtime via an interface — family of interchangeable behaviors.
cart.SetShipping(new FedExStrategy()); // Swap to DHL: cart.SetShipping(new DHLStrategy())
🏗️
Builder
Construct complex objects step by step. Common in query builders and report generators.
var q = new QueryBuilder() .From("Orders").Where("Status=1").Build();
🏠
Facade
Single simplified interface hiding subsystem complexity.
// Hides: inventory check, payment, email orderFacade.PlaceOrder(cart);
⚡
CQRS — Command Query Responsibility Segregation
Separate reads (Query) from writes (Command). Commands mutate state; Queries return data only.
// Command — mutates data await mediator.Send(new PlaceOrderCommand(cart)); // Query — reads data var orders = await mediator.Send(new GetOrdersQuery(userId));
07 — Architecture Styles
🏢 Monolith
One roof, one deployment
All layers in a single deployable project. Simple to start; harder to scale individual parts.
  • API / Application / Domain
  • Infrastructure / Persistence
  • Shared / Tests
🏬 Modular Monolith
Departments under one roof
Single deployment but isolated feature modules. Clean boundaries without distributed system complexity.
  • ProductModule / OrderModule
  • CustomerModule / PaymentModule
  • InventoryModule / Shared API
🌐 Microservices
Distributed specialized services
Each domain is a fully independent service. API Gateway routes traffic; Message Bus (RabbitMQ/Service Bus) handles async comms.
  • ProductAPI / OrderAPI
  • IdentityAPI / PaymentAPI
  • Gateway / MessageBus
🗂️
Domain-Driven Design (DDD)
Model code around the real business domain, not technical layers. Key building blocks: Aggregate, Entity, Value Object, Repository, Bounded Context, Ubiquitous Language.
08 — Tools & Misc Topics
⏱️
Hangfire
.NET background job library. Fire-and-forget, delayed, and recurring jobs. Auto-retries on failure.
BackgroundJob.Enqueue(() => SendEmail(userId)); RecurringJob.AddOrUpdate("cleanup", () => Cleanup(), Cron.Daily);
☁️
Azure Functions
Serverless — runs code on events (HTTP, timer, queue) with zero server management. Auto-scales.
// Runs every day at midnight UTC [TimerTrigger("0 0 * * *")] TimerInfo timer
🐳
Docker
Packages app + all dependencies into a container. Runs consistently on any machine — dev, staging, or cloud.
☸️
Kubernetes (K8s)
Orchestrates Docker containers — automates deployment, scaling, load balancing, and self-healing across clusters.
📨
Apache Kafka
High-throughput distributed event streaming. Used for real-time pipelines and async microservice communication (publish / subscribe model).
🔐
CSR (SSL)
Certificate Signing Request — generated on your server (IIS / Kestrel) and submitted to a CA (DigiCert, GoDaddy) to obtain an SSL/TLS certificate for HTTPS.
🔌
SOA (Service Oriented Architecture)
Design approach where software is composed of independent, reusable services communicating over a network (SOAP/REST). Predecessor to microservices — focused on enterprise integration.
