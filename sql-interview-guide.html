🔹 Basic SQL
Q01
What is the difference between WHERE and HAVING?
WHERE filters rows before grouping. HAVING filters after GROUP BY.
Example: Find departments where avg salary > 60k. 
SELECT Department, AVG(Salary)
FROM Employees
WHERE Status = 'Active'          -- rows first
GROUP BY Department
HAVING AVG(Salary) > 60000;   -- groups second
Q02
What are the types of JOINs in SQL?
JOIN TypeReturns
INNER JOINOnly matching rows from both tables
LEFT JOINAll left rows + matched right rows
RIGHT JOINAll right rows + matched left rows
FULL OUTER JOINAll rows from both sides
CROSS JOINCartesian product of both tables
SELF JOINTable joined with itself
-- Real-world: employees with their managers
SELECT e.Name, m.Name AS Manager
FROM Employees e
LEFT JOIN Employees m ON e.ManagerId = m.Id;
Q03
How do you find the second highest salary?
Use a subquery to exclude the max, then find the next max. 
SELECT MAX(Salary) AS SecondHighest
FROM Employees
WHERE Salary < (SELECT MAX(Salary) FROM Employees);

-- Best Practice: Use DENSE_RANK for Nth salary
SELECT Salary FROM (
  SELECT Salary, DENSE_RANK() OVER (ORDER BY Salary DESC) AS rnk
  FROM Employees
) AS t WHERE rnk = 2;
Q04
Difference between DELETE, TRUNCATE, and DROP?
DELETE — removes specific rows, supports WHERE, can rollback. Slow on large tables.
TRUNCATE — removes all rows instantly, no WHERE, no rollback (in most DBs), resets identity.
DROP — removes the entire table structure + data permanently.
DELETE FROM Logs WHERE CreatedAt < '2023-01-01';
TRUNCATE TABLE TempStaging;
DROP TABLE OldArchive;
Q05
What are aggregate functions in SQL?
Functions that operate on a group of rows and return a single value.
SUM()COUNT()AVG()MAX()MIN() 
SELECT Department,
       COUNT(*) AS Headcount,
       AVG(Salary) AS AvgSal,
       MAX(Salary) AS TopSal
FROM Employees
GROUP BY Department;
🔸 Intermediate SQL
Q06
What is a subquery? Give an example.
A query nested inside another query. Used for filtering, derived tables, or scalar values. 
-- Find employees earning above average
SELECT Name, Salary
FROM Employees
WHERE Salary > (SELECT AVG(Salary) FROM Employees);
Q07
How to find duplicate rows based on a column?
Group by the column and filter groups with count > 1. 
SELECT Email, COUNT(*) AS cnt
FROM Users
GROUP BY Email
HAVING COUNT(*) > 1;

-- To delete duplicates, keep only one with ROW_NUMBER()
Q08
How do indexes work in SQL?
An index creates a data structure (B-Tree) allowing the DB engine to find rows without full-table scans.

✅ Pros: Faster SELECT / WHERE / JOIN
⚠️ Cons: Slower INSERT/UPDATE, extra storage 
-- Create index on frequently filtered column
CREATE INDEX idx_email ON Users(Email);

-- Composite index for multi-column queries
CREATE INDEX idx_dept_sal ON Employees(Department, Salary);

🔷 Advanced SQL
Q10
What is a CTE (Common Table Expression)?
A named temporary result set scoped to a single query. Improves readability over nested subqueries. 
WITH ITStaff AS (
  SELECT * FROM Employees WHERE Department = 'IT'
)
SELECT Name, Salary
FROM ITStaff
WHERE Salary > 70000;
Q11
What is a window function?
Performs a calculation over a set of rows related to the current row without collapsing them into groups. 
-- Running total of sales per region
SELECT Region, SaleDate, Amount,
  SUM(Amount) OVER (PARTITION BY Region ORDER BY SaleDate) AS RunningTotal
FROM Sales;

Q13
What is a stored procedure?
Precompiled SQL logic saved in the DB. Improves performance and reuse. 
CREATE PROCEDURE GetEmployee @Id INT
AS
BEGIN
  SELECT * FROM Employees WHERE Id = @Id
END

-- Call it:
EXEC GetEmployee @Id = 101;
Q14
What are transactions in SQL?
A sequence of operations treated as a single unit — either all succeed or all fail. 
BEGIN TRANSACTION;
  UPDATE Accounts SET Balance -= 500 WHERE Id = 1;
  UPDATE Accounts SET Balance += 500 WHERE Id = 2;
IF @@ERROR <> 0
    ROLLBACK;
ELSE
    COMMIT;
🔴 Real-World Scenarios
Q15
How to update a column using values from another table?
Join the target table with a source table and set values from source. 
UPDATE e
SET e.Salary = n.Salary
FROM Employees e
JOIN NewSalary n ON e.Id = n.Id;

-- Best practice: test with SELECT first before UPDATE
Q16
Find rows in one table but NOT in another?
Use NOT EXISTS (better performance) or LEFT JOIN … WHERE NULL. 
-- Option 1: NOT EXISTS (preferred)
SELECT * FROM Orders o
WHERE NOT EXISTS (
  SELECT 1 FROM Invoices i WHERE o.Id = i.OrderId
);

-- Option 2: LEFT JOIN anti-pattern
SELECT o.* FROM Orders o
LEFT JOIN Invoices i ON o.Id = i.OrderId
WHERE i.OrderId IS NULL;
Q17
What is UNION vs UNION ALL?
UNION removes duplicates (slower). UNION ALL keeps all rows (faster). 
-- Use UNION ALL when duplicates are acceptable (faster)
SELECT Name FROM CurrentEmployees
UNION ALL
SELECT Name FROM FormerEmployees;

-- Use UNION when distinct results are required
Q18
How to pivot data in SQL Server?
Convert rows to columns using PIVOT or CASE + GROUP BY. 
-- CASE-based pivot (portable across DBs)
SELECT Department,
  SUM(CASE WHEN Quarter='Q1' THEN Revenue END) AS Q1,
  SUM(CASE WHEN Quarter='Q2' THEN Revenue END) AS Q2
FROM Sales
GROUP BY Department;
Q19

Guarantees for reliable database transactions:
PropertyMeaning
AtomicityAll or nothing — transaction fully completes or fully rolls back
ConsistencyData remains valid before and after the transaction
IsolationConcurrent transactions don't interfere with each other
DurabilityCommitted data persists even after a system crash
Q20
What is a view? When should you use it?
A virtual table based on a saved SELECT query. Use for security, simplification, and reuse. 
-- Create view for HR-safe employee data
CREATE VIEW EmployeeSummary AS
SELECT Id, Name, Department, YEAR(JoinDate) AS JoinYear
FROM Employees;

-- Query like a table
SELECT * FROM EmployeeSummary WHERE Department = 'Finance';
