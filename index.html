C# Fundamentals

The bedrock of all .NET development — master the language before the framework.

C# is a statically-typed, object-oriented language developed by Microsoft. It is the primary language for .NET applications. A strong C# foundation is essential before diving into any .NET framework.

Estimated time: 3–4 weeks for beginners, 1 week review for intermediate developers.

Language Basics

Object-Oriented Programming

Advanced C# Features

  • Follow C# Coding Conventions (Microsoft docs) consistently across the codebase.
  • Prefer var for local variable declarations when the type is obvious.
  • Use readonly for fields that don't change after construction.
  • Always use using statements or declarations for IDisposable resources.
  • Avoid magic strings/numbers — extract into named constants or enums.
  • Prefer composition over inheritance for flexibility.
  • Write async all the way — avoid mixing sync/async code.
  • Use ConfigureAwait(false) in library code to avoid deadlocks.

SQL & Databases

Relational databases are the backbone of most enterprise applications.

Understanding SQL and relational database design is critical for any backend developer. You'll work with SQL Server primarily, though the concepts transfer to PostgreSQL, MySQL and others.

SQL Fundamentals

Database Design

SQL Server Specific

  • Always use parameterized queries to prevent SQL injection.
  • Index columns used in WHERE clauses and JOIN conditions.
  • Use transactions for multi-step operations that must be atomic.
  • Avoid SELECT * — list only required columns for performance.
  • Use CTEs for readability when subqueries become complex.
  • Regularly analyse execution plans to identify slow queries.
03

.NET Core

Cross-platform, high-performance runtime and framework ecosystem.

.NET Core (now simply ".NET 8+") is a free, open-source, cross-platform successor to .NET Framework. Understanding the runtime model, CLI tooling, and the host/configuration system is fundamental.

Runtime & Tooling

Application Model

  • Use Dependency Injection for all services — avoid static state and service locators.
  • Choose the correct service lifetime: Singleton → Scoped → Transient.
  • Store sensitive config in User Secrets (dev) or Azure Key Vault (prod).
  • Structured logging with contextual properties, not string concatenation.
  • Pin your SDK version using global.json for reproducible builds.
04

ASP.NET Core MVC

Model-View-Controller pattern for full-stack web application development.

ASP.NET Core MVC provides a pattern-based way to build dynamic websites. The framework handles routing, model binding, validation, view rendering (Razor), and filter pipelines.

  • Keep controllers thin — delegate business logic to services.
  • Always use ViewModels, never expose domain entities directly to views.
  • Validate input server-side regardless of client-side validation.
  • Use PRG pattern (Post-Redirect-Get) to prevent duplicate form submissions.
  • Use Areas to organise large applications by feature domain.
05

Web API

Build RESTful and HTTP services that power modern frontends and mobile apps.

ASP.NET Core Web API allows you to build HTTP services following REST principles. You'll learn API design, serialisation, versioning, authentication, and documentation with Swagger/OpenAPI.

REST Principles & Design

Implementation

Security & Performance

  • Return Problem Details for all error responses (RFC 7807).
  • Version APIs from the start — never break existing consumers.
  • Use FluentValidation for complex validation logic.
  • Document all endpoints with Swagger — treat it as a contract.
  • Implement idempotency keys for POST endpoints that create resources.
  • Always set appropriate Cache-Control headers.
06

LINQ

Language Integrated Query — expressive data querying built into C#.

LINQ provides a uniform query syntax for collections, databases (via EF Core), XML, and more. Mastering LINQ dramatically increases code readability and expressiveness.

  • Understand when queries are deferred — avoid unintentional multiple enumerations.
  • Use AsNoTracking() in EF Core for read-only queries.
  • Project to DTOs with Select() to avoid over-fetching data.
  • Prefer FirstOrDefault over First when null is an expected outcome.
  • Profile generated SQL in EF Core — LINQ doesn't always produce optimal queries.
07

Entity Framework Core

Modern ORM for .NET — map C# objects to relational database tables.

EF Core is a lightweight, extensible ORM enabling .NET developers to work with databases using .NET objects, eliminating most data-access code. It supports Code-First and Database-First workflows.

Core Concepts

Querying & Persistence

Advanced

  • Use AsNoTracking() for all read-only queries to boost performance.
  • Never expose DbContext directly from controllers — wrap in repositories or services.
  • Always check generated SQL using logging or EF profiler.
  • Use explicit loading instead of lazy loading in web applications.
  • Implement optimistic concurrency with row version tokens for multi-user scenarios.
08

Testing

Ensure correctness, reliability and confidence in your .NET applications.

Testing is a first-class concern in modern .NET development. The ecosystem offers mature tools: xUnit for unit tests, Moq for mocking, and WebApplicationFactory for integration tests.

Unit Testing

Integration & E2E Testing

Quality Metrics

  • Follow the testing pyramid: many unit tests, fewer integration, fewest E2E.
  • Tests should be FIRST: Fast, Isolated, Repeatable, Self-validating, Timely.
  • Never test implementation details — test observable behaviour.
  • Aim for meaningful coverage, not 100% for the sake of it.
  • Run tests in CI on every PR — don't merge broken builds.
09

DevOps

Ship faster, safer, and more reliably with modern DevOps practices.

DevOps bridges development and operations. For .NET Core developers, this means containerisation with Docker, CI/CD with GitHub Actions or Azure DevOps, and cloud deployment on Azure.

Source Control

CI/CD

Containerisation

Cloud (Azure)

  • Use multi-stage Docker builds to keep production images minimal.
  • Never store secrets in container images or source control — use secret stores.
  • Use health checks (/health endpoint) in all ASP.NET Core apps.
  • Implement blue/green or canary deployments for zero-downtime releases.
  • Tag all deployments with the commit SHA for full traceability.

Advanced Topics

Level up from mid-level to senior with architectural patterns and performance.

Advanced topics cover architectural patterns, real-time communication, distributed systems, security hardening, and performance engineering — the skills that distinguish senior .NET engineers.

Architecture

Communication & Messaging

Performance & Caching

Security

  • Apply Clean Architecture from the start — it's hard to retrofit.
  • Use MediatR to decouple request handling from controllers.
  • Cache at the right layer — not everything needs Redis.
  • Design microservices around business capabilities, not technical layers.
  • Treat security as a first-class requirement, not an afterthought.
