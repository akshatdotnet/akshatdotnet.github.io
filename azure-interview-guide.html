# Azure Service What It Is Real-Time Example Skills You Learn
1 Azure Virtual Machine (VM) Cloud-based Windows/Linux server Hosting ASP.NET Core ecommerce application Server setup, IIS, Linux, Networking
2 Azure Functions Serverless code execution Send email after user registration Automation, APIs, Event-driven architecture
3 Azure Blob Storage Store files, images, videos Store ecommerce product images File storage, backups, SAS tokens
4 Azure Disk Storage Persistent VM storage Store database files inside VM Storage management, disk optimization
5 Azure Synapse Analytics Big data analytics platform Analyze sales and reports Data warehouse, ETL, SQL analytics
6 Azure DNS Manage domain names Connect domain to Azure website DNS records, domain management
7 Azure Load Balancer Distribute traffic across servers Balance users between multiple servers High availability, traffic routing
8 Azure CDN Fast content delivery network Load images quickly worldwide Caching, performance optimization
9 Azure Cosmos DB NoSQL distributed database Store chat application data NoSQL, JSON, global replication
10 Azure SQL Database Managed SQL Server database Store orders and users SQL, optimization, cloud database
11 Azure Cache for Redis In-memory cache system Cache product catalog for faster loading Caching, performance tuning
12 Azure Event Hubs Big data streaming platform Process IoT sensor data Real-time streaming, telemetry
13 Azure HDInsight Hadoop/Spark big data service Analyze huge application logs Hadoop, Spark, big data processing
14 Computer Vision AI image recognition service OCR invoice document scanning AI integration, OCR, image processing
15 Azure Service Bus Reliable message communication Order service communicates with payment service Microservices, async communication
16 Azure Queue Storage Simple queue system Background email processing Background jobs, async processing
17 Azure Monitor Monitoring and diagnostics tool Track API errors and CPU usage Logging, alerts, monitoring
